PREFACE — はじめに

本書の目的と前提

Spring Boot をクラウドへ無料でデプロイしたい。

しかし H2 はインスタンス停止と同時にすべてを失う ——

「揮発するDB」は本番運用に値しない。

QUESTION 01

どうすれば
完全に永続化できるか

Render の Web Service だけでは不十分。外部マネージド PostgreSQL との組み合わせで、コードもデータも壊さずに無料運用する。

QUESTION 02

スリープ復旧は
どう扱うか

Neon は 0.5秒で自動復旧。Supabase は 7日放置で一時停止 となるが、ヘルスチェックで予防できる。

QUESTION 03

どの構成を
選べばよいか

長期放置のポートフォリオなら Neon。アクティブ開発と機能拡張なら Supabase。本書は両方を完全な手順で示す。
